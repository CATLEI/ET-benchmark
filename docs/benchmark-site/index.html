04 / Methods

How we compare

Compare reconstruction quality under controlled missing-wedge and sparse-view conditions. One table may list every algorithm; “best” is tagged only on claim metrics, and only within each method family.

Claim metrics by family

Family Examples Primary claim Not a claim
classical WBP, FBP, SIRT, GENFIRE Affine SSIM / CC vs GT Raw PSNR alone; wall-clock ranking
TV regularized iterative TVM Affine SSIM / CC (+ morphology when fixed) Train+infer wall-clock vs classical
grey prior DART, TVR-DART Affine SSIM / CC + Dice Blind “overall champion” vs Track A
self-supervised IsoNet, DeepDeWedge, WUCON Wedge-out CC + wedge-in CC Global PSNR as sole score

Tasks: general = SM_70 @ 1° · missing wedge = Axis W (tilt) · sparse view = Axis S (step). Experimental / no-GT samples use held-out reprojection — never treat ±70° WBP/SIRT as GT.

What the board sorts on

Default columns and sort use the task’s claim metrics (protocol_* when audited; otherwise provisional SSIM/Dice). PSNR and runtime stay under Metrics and never receive “best” tags.

Timing (diagnostic)

Runtime is optional and never tags “best”. Classical iterate, TV/DART loops, and learning train vs infer are not commensurate — compare within family or split train/infer when recorded.

No single champion

No overall score across tasks or families. Failures remain as rows. Protocol details: ET_TOMO_BENCHMARK_PROTOCOL.md.
